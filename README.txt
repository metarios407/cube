내 큐브 연구소 — 개인용 iPhone PWA

기능: 3D 큐브 회전/시점 변경, 22수 랜덤 셔플, 회전 기호 한국어 설명, 앱 내 회전 기록 역순 복원, 공식 연습, 타이머/기록 저장.

중요 제한: 실제 큐브의 6면 색상을 카메라로 스캔하거나 직접 입력하여 범용 풀이를 계산하는 기능은 포함되지 않습니다. 자동 복원은 이 앱에서 발생한 회전 기록만 되돌립니다. 3D 회전은 단계별 즉시 상태 갱신이며 실제 면 회전 애니메이션은 아닙니다.

아이폰 설치:
1. 이 폴더 전체를 HTTPS 정적 웹호스팅(예: GitHub Pages, Netlify)에 업로드하세요. 로컬 file:// 로 열면 PWA 설치/오프라인 캐시가 동작하지 않을 수 있습니다.
2. 아이폰 Safari에서 배포된 HTTPS 주소로 접속합니다.
3. 공유 버튼 → 홈 화면에 추가 → 추가.
4. 홈 화면의 '큐브 연구소'를 실행합니다.

별도 계정/백엔드가 필요하지 않습니다. 타이머 기록은 기기 localStorage에 저장됩니다.
